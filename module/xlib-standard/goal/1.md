# xlib-standard v1.0.0 发布 Goal 执行文档

> 文件用途：作为 `xlib-standard` v1.0.0 发布改造的唯一可执行 goal 文档。  
> 执行原则：只保留模板库标准源所需能力；删除治理运行时、下游矩阵和冗余 evidence 系统。  
> 版本目标：`v1.0.0`。  
> 适用仓库：`github.com/ZoneCNH/xlib-standard`。  
> 判定方式：逐项执行、逐项打勾、逐项产出 evidence。

---

## 0. 最终目标

把 `xlib-standard` 收敛为 Go 基础库模板标准源，只负责四件事：

```text
1. 定义标准
2. 提供可编译参考模板
3. 生成独立基础库
4. 用最小 gate 验证模板和生成库
```

v1.0.0 发布后，开发者只需要知道三条命令：

```bash
scripts/render_template.sh --module-path <module-path> --package-name <package-name> --out <dir>
GOWORK=off make ci
GOWORK=off make release-check
```

最终完成声明必须是：

```text
DONE with evidence:
- manifest: release/manifest/latest.json
- checksum: release/manifest/latest.json.sha256
- gates: passed
```

## 6. PR-3：收敛 Makefile、scripts、CI

### 6.1 Makefile 最终内容

```makefile
SHELL := /usr/bin/env bash

GO ?= go
GOWORK ?= off

.PHONY: fmt
fmt:
	$(GO) fmt ./...

.PHONY: vet
vet:
	GOWORK=$(GOWORK) $(GO) vet ./...

.PHONY: lint
lint:
	@if command -v golangci-lint >/dev/null 2>&1; then \
		golangci-lint run ./...; \
	else \
		echo "golangci-lint not installed"; \
		exit 1; \
	fi

.PHONY: test
test:
	GOWORK=$(GOWORK) $(GO) test ./...

.PHONY: race
race:
	GOWORK=$(GOWORK) $(GO) test -race ./...

.PHONY: contracts
contracts:
	./scripts/check_contracts.sh

.PHONY: boundary
boundary:
	./scripts/check_boundary.sh

.PHONY: render-smoke
render-smoke:
	./scripts/check_rendered_template.sh

.PHONY: security
security:
	./scripts/check_security.sh

.PHONY: ci
ci: fmt vet lint test race contracts boundary render-smoke security

.PHONY: release-check
release-check: ci
	./scripts/release_check.sh

.PHONY: release-final-check
release-final-check: release-check
	./scripts/release_final_check.sh
```

```text

4. 替换 module path。
5. 将 pkg/templatex 移动为 pkg/<package-name>。
6. 替换包名、README、docs、contracts 中的模板占位符。
7. 在生成目录执行 GOWORK=off go test ./...。
```

```go
func New(ctx context.Context, cfg Config, opts ...Option) (*Client, error)
```

### 7.3 Config 标准

```text
所有配置显式传入
不得读取环境变量
不得读取文件
不得内置生产 endpoint
Validate 检查必填字段和非法值

```

```text

auth
timeout
unavailable
```

```text

```

### 7.5 Metrics 只能要求 5 个 P0 指标

```text
client_created_total
client_closed_total
client_errors_total
client_health_status
client_health_latency_ms
```

```text
op
kind
status
```

P0 禁止 label：

```text
name
user_id
request_id
trace_id
span_id
order_id
tenant_id
account_id
email
phone
token
secret
password
dsn
url
endpoint
```

### 7.6 Health 标准

```text
nil context => unhealthy
canceled context => unhealthy
zero-value client => unhealthy
closed client => unhealthy
initialized and open client => healthy
degraded 只作为具体库扩展
Metadata 默认不填
```
