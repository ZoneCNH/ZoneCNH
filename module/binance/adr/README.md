## ADR 编号规则

- 编号格式：`ADR-NNN`（三位数字，从 001 起）
- 文件名：`ADR-NNN-{slug}.md`
- ADR-001 保留给模块创建决策（如需要可后补）
- 模板：`docs/governance/module-governance/templates/ADR-MODULE-ONBOARDING.md`

## 活跃文档

ADR 是历史决策记录，不替代活跃规格文档。当前架构决策以 `SPEC.md` 为准。
