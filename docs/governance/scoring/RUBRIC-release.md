# Release 评分 Rubric

> 评分对象：发布清单、G10 Release Gate 检查结果、部署验证证据
> 总分：100。

## 维度（满分 100）

| 维度 | 满分 | 检查重点 |
|------|------|----------|
| Gate 全部通过 | 18 | G0-G9 所有必备 Gate 状态为 PASS |
| 回滚方案就绪 | 15 | 回滚步骤已文档化，回滚验证已测试 |
| 监控与告警 | 12 | 发布后监控已配置，关键指标告警阈值已设置 |
| 文档同步 | 12 | README、CHANGELOG、API 文档已更新 |
| 变更通知 | 10 | 相关方已通知，维护窗口已协调 |
| 发布清单完整 | 13 | 所有检查项逐条完成并记录 |
| 上线验证计划 | 10 | 发布后的冒烟测试和验证步骤已定义 |
| 版本与标签 | 10 | 版本号遵循语义化，Git 标签已创建 |

## 阶段特定红线

- 任一必备 Gate（G0-G9）未通过。
- 无回滚方案。
- 关键监控未配置。
- 变更通知未发送。

## 通过门禁

所有 Gate 通过、回滚方案就绪、监控已配置、文档已同步 → 进入 Retrospective 阶段。
