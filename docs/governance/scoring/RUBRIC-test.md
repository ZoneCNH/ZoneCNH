# Test 评分 Rubric

> 评分对象：测试执行结果、测试覆盖率报告、测试输出证据
> 总分：100。

## 维度（满分 100）

| 维度           | 满分   | 检查重点                                     |
| -------------- | ------ | -------------------------------------------- |
| TC 覆盖完整    | 18     | 矩阵中每个 TC 都有对应测试用例               |
| 测试通过率     | 15     | 所有测试通过，无跳过或预期失败未说明         |
| AC 验证证据    | 15     | 每条 AC 有可观察的测试输出证明满足           |
| 边界与异常覆盖 | 12     | 边界条件、异常路径、错误恢复有测试覆盖       |
| 覆盖率达标     | 10     | 代码覆盖率满足 Spec 定义的目标（通常 ≥ 80%） |
| 测试隔离性     | 10     | 测试之间无状态泄漏，可独立运行和重复运行     |
| 性能基准       | 10     | 性能相关的 NFR 有基准测试和度量结果          |
| 证据可追溯     | 10     | 测试输出关联到 AC/TC ID，可回溯到 Spec       |

## 阶段特定红线

- 存在 TC 无对应测试用例（验证盲区）。
- 测试运行失败未修复。
- 覆盖率低于 Spec 定义的最低要求。
- 测试输出未记录或不可复现。
- 存在硬编码的测试数据泄露真实凭证。

## 通过门禁

所有 TC 对应测试通过、覆盖率达标、AC 验证证据完整、无红线 → 进入 Review 阶段。
