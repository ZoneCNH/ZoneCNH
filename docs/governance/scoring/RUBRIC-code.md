# Code 评分 Rubric

> 评分对象：当前 Task 的 diff、新增/修改测试、验证命令输出证据。
> 总分：100。

## 维度（满分 100）

| 维度              | 满分   | 检查重点                                        |
| ----------------- | ------ | ----------------------------------------------- |
| Task scope 符合度 | 15     | 仅修改 Prompt 允许的文件；无 scope 外变更       |
| FR/AC 覆盖        | 15     | 实现覆盖 Prompt 引用的所有 FR/AC                |
| 测试覆盖          | 15     | 新增/更新测试覆盖所有 TC；覆盖率达 spec 要求    |
| 测试通过证据      | 12     | 实际运行了 lint/typecheck/test/race，输出已记录 |
| 代码质量          | 10     | 命名、可读性、错误处理、无明显坏味道            |
| 安全与边界        | 10     | 无硬编码 secret、输入校验、边界处理符合 spec    |
| 文档与注释        | 8      | 公共接口有 doc 注释；变更影响文档已同步         |
| 追溯证据回填      | 8      | TRACEABILITY.md Status 更新、Task 状态更新      |
| 无破坏性影响      | 7      | 现有测试仍通过；公共契约未破坏                  |

## 阶段特定红线

- 修改了 Prompt 未授权的文件。
- 引入 Spec 外功能。
- 任一 FR/AC 未覆盖。
- 测试未运行或运行失败。
- 出现硬编码凭证、密钥、敏感日志。
- 引入新依赖未在 Task 中声明。
- 破坏现有测试。
- TRACEABILITY.md 未更新。

## 通过门禁

`composite_score = min(四源评分)` 且 `composite_score >= 98`、无红线、无 LLM 低置信度、LLM 分差与 rules 异构分歧在阈值内 → Task Done，进入下一 Task 或 Feature 验收。
