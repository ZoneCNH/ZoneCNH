# L2.5 领域共享层实现规范

> **效力层级**：`CONSTITUTION.md` §1（P7/P8）、§4、§7.4、附录 L2.5 > 本文档 > `go-coding-standards.md`

---

## 1. 层定义

| 属性 | 要求 |
|------|------|
| 可依赖 | `kernel`（L0） |
| 禁止依赖 | L1 运行时、业务域、transport/HTTP/WS/Kafka/ORM |
| 测试覆盖率 | **≥ 80%** |

**v1.0.0 收口依赖顺序**：`decimalx` → `domain_market` → `domain_macro` → `domainx` → `domain_exchange`

## 2. 金融数值：禁止 float64（CONSTITUTION 附录 L2.5）

**最重要约束**：所有公开金融数值字段禁止 `float64`。

```go
// Bad
type Tick struct{ Price float64 } // ❌ 精度丢失：0.1+0.2=0.30000000000000004

// Good
type Tick struct{ Price decimal.Decimal } // ✅ JSON 输出带引号字符串

// 构造必须用字符串解析
price, err := decimal.Parse("123.45")  // ✅
price := decimal.FromFloat64(123.45)   // ❌ 已精度丢失

// 除法必须显式舍入上下文
ctx := decimalx.NewContext(8, decimalx.RoundHalfUp)
result, err := a.DivWithContext(b, ctx) // ✅
```

### Money 跨币种保护

```go
usd := decimalx.NewMoney(decimalx.Parse("100"), decimalx.USD)
cny := decimalx.NewMoney(decimalx.Parse("700"), decimalx.CNY)
_, err := usd.Add(cny) // err: "cannot add USD and CNY"
```

## 3. 值对象不可变性（CONSTITUTION §4.1）

```go
// Bad：提供 setter
func (t *Tick) SetPrice(p decimal.Decimal) { t.price = p } // ❌

// Good：私有字段 + 只读方法 + 返回新值
type Tick struct{ symbol string; price decimal.Decimal }

func (t Tick) Price() decimal.Decimal { return t.price }

func (t Tick) WithPrice(p decimal.Decimal) Tick {
    t.price = p // 值拷贝，安全
    return t
}

// 工厂函数一次性赋值
func NewTick(symbol string, price decimal.Decimal, ts time.Time) (Tick, error) {
    if symbol == "" {
        return Tick{}, errx.New(errx.KindValidation, "domain_market: symbol required")
    }
    return Tick{symbol: symbol, price: price}, nil
}
```

## 4. JSON 与 SQL 边界

```go
// JSON：必须输出带引号字符串
data, _ := json.Marshal(decimalx.MustParse("123.456"))
// data = `"123.456"` ✅（不是 123.456）

// SQL：必须拒绝 float64 输入
func (d *Decimal) Scan(src any) error {
    switch v := src.(type) {
    case string:  return d.UnmarshalText([]byte(v))
    case float64: return fmt.Errorf("decimalx: refusing float64, use NUMERIC column") // ❌ 拒绝
    case nil:     *d = Decimal{}; return nil
    }
}
```

推荐 DB 列类型：`NUMERIC(38,18)` 或 `TEXT`，禁止 `FLOAT`/`DOUBLE`。

## 5. 禁止暴露 Transport DTO

```go
// Bad：领域模型携带 transport 细节
type Tick struct {
    Price      decimal.Decimal `json:"p"`          // ❌ 交易所原始字段名
    KafkaTopic string          `json:"-"`          // ❌ 传输细节
    TDTag      string          `tdengine:"tag"`    // ❌ ORM tag
}

// Good：纯领域模型，adapter 在数据域内部负责映射
type Tick struct {
    Symbol    string
    Price     decimal.Decimal
    Timestamp time.Time
}
```

## 6. 跨模块语义 SSOT（CONSTITUTION §1.2 P8）

```go
// Bad：各域重复定义 Price 类型
// riskx: type Price struct{ Value float64 }
// factor_engine: type Price decimal.Decimal

// Good：统一使用 L2.5
import "github.com/ZoneCNH/decimalx"
type Position struct{ Cost decimalx.Money } // ✅

// Topic SSOT：domain_market 定义，其他模块引用不得重新定义
const TopicMarketTick = "market.tick" // dot.case（CONSTITUTION §7.4）
```

## 7. 命名规范（CONSTITUTION §7.4）

| 层面 | 规范 | 示例 |
|------|------|------|
| 模块/仓库/目录 | snake_case | `domain_market`, `domain_macro` |
| JSON/YAML 配置 key | snake_case | `series_code`, `available_at` |
| Go 导出类型/常量 | PascalCase | `MacroPoint`, `TopicMacroData` |
| Topic literal | dot.case | `macro.data`, `market.tick` |

禁止：`macroData`（camelCase）、`macro_data_topic`（Topic 非 dot.case）。

## 8. 测试规范

```go
// 数值比较必须用 Equal()，禁止 float 比较
expected, _ := decimal.Parse("123.45")
if !got.Price.Equal(expected) { t.Errorf(...) }

// 边界条件（CONSTITUTION §4.4）
func TestMoney_Add_CrossCurrency_ReturnsError(t *testing.T) {
    _, err := usd.Add(cny)
    if err == nil { t.Fatal("expected cross-currency error") }
}

// 不可变性测试
func TestTick_WithPrice_OriginalUnchanged(t *testing.T) {
    orig, _ := domain_market.NewTick("BTC", decimalx.MustParse("50000"), time.Now())
    mod := orig.WithPrice(decimalx.MustParse("51000"))
    if !orig.Price().Equal(decimalx.MustParse("50000")) {
        t.Error("original should not be modified")
    }
}
```

## 9. 禁止事项

| 禁止 | 原因 |
|------|------|
| `float64` 表示金融数值 | 精度（CONSTITUTION 附录 L2.5） |
| setter 方法 | 不可变性（CONSTITUTION §4.1） |
| transport DTO / ORM tag | 纯领域模型（CONSTITUTION 附录 L2.5） |
| import L1 运行时 | 依赖方向（CONSTITUTION §3.4） |
| 各域重复定义共享概念 | SSOT（CONSTITUTION §1.2 P8） |
| `decimal.FromFloat64()` | 已精度丢失 |
| Topic 用 snake_case | 必须 dot.case（CONSTITUTION §7.4） |

### decimalx
```go
var (
    PriceCtx  = decimalx.NewContext(8, decimalx.RoundHalfUp) // 价格 8 位
    VolumeCtx = decimalx.NewContext(8, decimalx.RoundDown)    // 数量截断
    FeeCtx    = decimalx.NewContext(18, decimalx.RoundHalfUp) // 费率 18 位
)
// MustParse 只用于常量初始化和测试，生产代码用 Parse()
```

### domain_macro
```go
type MacroPoint struct {
    SeriesCode    string

    AvailableAt   time.Time       // 发布时点（≥ ObservedAt，防前视偏差）
    Value         decimal.Decimal
    Revision      int
    IsPreliminary bool
}

// 回测查询：只可见 AvailableAt <= asOf 的数据
func FilterVisible(pts []MacroPoint, asOf time.Time) []MacroPoint { ... }
```

### domainx
```go
// OrderState 有限状态机
func (s OrderState) TransitionTo(next OrderState) error {
    if !isValidTransition(s, next) {
        return fmt.Errorf("domainx: invalid transition %s → %s", s, next)
    }
    return nil
```
