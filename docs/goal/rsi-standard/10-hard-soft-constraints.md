# 10. RSI 的硬约束与软约束

## 10.1 硬约束

硬约束是系统层面不可绕过的限制：

```text
不能访问 hidden eval
不能删除日志
不能自授权限
不能自动部署
不能导出权重
不能修改 kill switch
不能控制评测器
不能让后继者自动继承权限
```

硬约束必须由外部系统执行，而不是由模型自觉遵守。

## 10.2 软约束

软约束是行为引导：

```text
system prompt
安全指令
训练偏好
RLHF
政策提醒
自我解释要求
风险意识训练
```

软约束有用，但不能替代硬约束。

最危险的错误是：

```text
用 prompt 约束 RSI。
```

对于完整 RSI，prompt 只能是辅助控制，不能是安全边界。
