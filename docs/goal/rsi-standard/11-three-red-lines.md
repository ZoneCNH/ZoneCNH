# 11. RSI 的三条红线

## 11.1 红线一：自我批准

```text
AI 不能批准自己进入下一代。
```

禁止 AI 自行决定：

```text
我更好了
我可以部署
我可以获得更多权限
我可以训练下一代
```

## 11.2 红线二：控制评测

```text
AI 不能控制判断自己是否变好的标准。
```

禁止：

```text
修改评测器
读取 hidden eval
污染测试集
伪造结果
选择性报告
```

## 11.3 红线三：自主扩权

```text
AI 不能自己获得更多资源、权限、网络、算力、权重和部署能力。
```

否则 RSI 会从技术闭环变成权力闭环。
