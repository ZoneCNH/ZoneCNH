ZoneCNH/FoundationX 量化交易基础设施的治理文档枢纽仓。不含应用代码，核心交付物是 Markdown 治理文档、69 个模块的规格制品（spec/matrix/plan/tasks）和交付管线规范。模块实现位于 github.com/ZoneCNH 下各自独立仓库，本仓库只描述、索引和治理它们。
